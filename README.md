# 🌐 Portfolio Website  

Website ini merupakan **proyek kolaboratif** yang dikembangkan oleh [Ariel](https://github.com/Kiana0130), [Ferdi](https://github.com/ferdiTRG), dan [Akmal](https://github.com/akmalnezu).  
Tujuannya adalah untuk membangun sebuah **personal portfolio website** yang modern, interaktif, dan responsif sebagai showcase karya, skill, dan pengalaman kami.  

## ✨ Fitur Utama  
- **Desain Responsif**: Optimal di desktop, tablet, dan mobile.  
- **UI/UX Modern**: Menggunakan layout minimalis dengan sentuhan animasi interaktif.  
- **Section Personal**: Menampilkan profil, skill, pengalaman, dan proyek.  
- **Integrasi GitHub**: Showcase otomatis dari repositori proyek.  
- **Dark/Light Mode**: Pengguna bisa memilih tema sesuai preferensi.  

## 🛠️ Teknologi yang Digunakan  
- **Frontend**: HTML5, CSS3, JavaScript.  
- **Styling**: Tailwind CSS / Bootstrap.  
- **Deployment**: GitHub Pages / Vercel / Netlify.  
- **Kolaborasi**: Git & GitHub untuk version control.  

## 🎯 Tujuan Proyek  
- Melatih kerja sama tim dalam pengembangan web.  
- Membangun portfolio yang dapat digunakan secara nyata.  
- Menerapkan praktik terbaik dalam **web development** modern.
